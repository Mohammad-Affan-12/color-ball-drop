# Cut & Cascade

Existing Godot 4.7.2 offline physics puzzle game: 100 levels, five chapters, free hints/retries, stars, cosmetic trails and a daily campaign selection.

Start with [release readiness and verification](docs/RELEASE_READINESS.md). Real AdMob/UMP uses test IDs and stays gated pending owner audience/account review. Remote analytics is separately opt-in and intentionally unconfigured. No publishing is automated.
