## Platform packaging

**YouTube Shorts:** title “Which rope goes first? | Cut & Cascade”; description “Real level 3 gameplay from my free offline physics puzzle. Campaign hints and retries are free. [PLAY_STORE_LINK_AFTER_RELEASE]”; pinned comment asks for a cut order. Use original vertical footage and an accurate thumbnail frame. Do not claim an unavailable store link works.

**TikTok:** on-screen hook in the first second; caption “Steel ball first, or colors first? Real gameplay from my puzzle game.” Keep the game large and put explanations in captions. Use 3–5 relevant tags, not a wall of unrelated trending tags. Enable bio link only when the account/platform allows it; otherwise use the exact app name in the caption.

**Instagram Reels:** cover “WHICH ROPE FIRST?” using a real untouched board; caption “A three-cut chain reaction. Save this if you want to try it after the reveal. Cut & Cascade: Color Puzzle.” Use an owner-provided working bio link after release and add alt text describing the visible puzzle. Do not imply app install attribution from video views alone.

## Recording checklist and learning loop

Record a clean unsolved board for 1–2 seconds, visible real swipes, a complete cascade and a short result. Keep UI readable within top/bottom/right platform safe areas. Do not promise exact device performance from desktop footage. Retain original masters and record a matching device clip before large-scale promotion. Review each final MP4 end to end. Draft → owner review → manual upload → collect observations; no automatic publishing.

Use [content-tracker.csv](content-tracker.csv) for clip/level, hook, platform, language, plays, 2-second hold (where supplied), average watch duration, completion, saves, profile visits, link clicks and release-country store conversion. Its generated-draft rows have intentionally empty publishing and performance fields; no results are invented. Use “not available” when a metric is unavailable. Compare clips of similar length; test one change at a time and keep meaningful sample-size caveats. Publish useful puzzle challenges and answer real comments; respect community self-promotion rules. Do not spam groups, buy engagement or trade incentivized reviews.
